# Price Manager

## Objetivo
Inicializar la estructura base del proyecto.

## Introducción
Este proyecto busca mantener de forma actualizada los precios del catalogo de la tienda star computación y gestionar el stock de los productos.
Para llevar a cabo este proyecto las tecnologias que utilizaremos seran python como lenguaje de programación y POO como paradigma de programación.

## Contexto
En este sprint se crea la base del sistema y se configura Git.
